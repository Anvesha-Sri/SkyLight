# 🌤️ SkyLight - Live Weather Dashboard

[![Live Demo](https://img.shields.io/badge/Live_Demo-✨_Try_Now-38bdf8?style=for-the-badge&logo=vercel&logoColor=white)](https://your-demo-link.com)

A beautiful, modern weather web application that provides real-time weather updates with **immersive dynamic background videos** that automatically change according to the current weather condition.

---

## 🚀 Why I Built SkyLight?

While most weather websites are functional but visually static, I wanted to create an experience that feels **alive and immersive**. 

I built **SkyLight** to combine accurate weather data with stunning visuals, turning a simple weather check into an engaging moment.

### How This Project Satisfies the Goal:

- **Immersive Experience**: The background video intelligently switches based on weather (Clear, Rain, Thunderstorm, Snow, Clouds, Haze, etc.), making users feel the weather rather than just reading it.
- **Rich Information**: Displays detailed weather metrics including Temperature, Feels Like, Humidity, Pressure, Wind Speed, Sea Level, and Coordinates.
- **User-Centric Design**: Fast search, smooth interactions, proper error handling, and fully responsive layout.

This project showcases my ability to build **beautiful, functional, and engaging** web applications using vanilla JavaScript.

## ✨ Key Features

- 🎬 **Dynamic Background Videos** - The background video changes automatically based on weather conditions (Clear, Rain, Cloud, Thunderstorm, Haze, Snow, etc.)
- 🌡️ **Real-time weather data** for any location worldwide
- 📊 **Detailed Weather Information**:
  - Temperature & Feels Like
  - Humidity & Pressure
  - Wind Speed & Sea Level
  - Latitude & Longitude
- 🔍 **Search any city**
- 📱 **Fully responsive** and clean UI
